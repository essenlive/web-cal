# Feature backlog

Ideas not yet scheduled into a spec. Pull one into `specs/` when it's ready to build.

- [ ] **Global theming** — replace the light/dark-only toggle with a theme selector; allow creating/saving more than two named themes.
- [ ] **Settings export/import** — export all app settings (connections, types, rules, preferences) to a single `.json` file, and import it back.
- [ ] **Quick hide** — a fast way to toggle visibility of individual data sources and display types without deleting them.
- [ ] **Presets** — save/switch between named combinations of source & type visibility (e.g. "Work": only work calendar; "Personal": only personal events).
- [ ] **Keyboard shortcuts** — view switching (month/week/day), preset switching (1/2/3…), and navigation (arrow keys = next day, shift+arrow = next month, etc).
